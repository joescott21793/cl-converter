Vertex conversion reference table (12 mm)

FCL = F / (1 − d·F), d = 0.012 m. Rounded to the nearest 0.25 D; ties go to less minus / more plus. Below about ±4.00 D the change is under 0.25 D, so the glasses power carries over.
